# Platforms the reference site lists that ERIO does not cover yet

Read from the public page https://jobindex.space/sources on 2026-11-10: **232 sources**, 4.8 million jobs. The page names each
source and its job count, and nothing else: it does not say how the sources were found. The usual way (and what ERIO does) is
that each vendor publishes a public job feed per employer, and employers are found from archives, sitemaps and company lists.
About 20 of the 232 are single-employer career sites (Amazon, EPAM, Sber and so on), which are company pages, not platforms.

ERIO already covers roughly 93 of the 232 by name (78 platforms plus public services, counting blocked ones). The rest:
